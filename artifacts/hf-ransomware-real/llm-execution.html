Raw evidence search

search_raw_evidence
Role
IOC pivot across raw logs and command output.
Implementation
Case-insensitive line scan over the local bundle: up to 8 literal terms, OR by default or AND, optional source prefix, first 25 matches. No regex or semantic search.
Output
Excerpt, source path, line number, SHA-256 and stable EV ID.

DECIDE

Exfiltration assessment

assess_exfiltration
Role
Separate attempted transfer from confirmed data loss.
Implementation
State machine over exfiltration events and telemetry markers: external success → confirmed; host-only completion → possible; blocked event → attempted; no event → not_observed.
Output
Status, confidence, evidence IDs, telemetry sources and coverage limits.
